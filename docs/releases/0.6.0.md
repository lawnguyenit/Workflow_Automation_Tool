# 0.6.0 — Gmail send output

## Added

- Added `gmail.send`, a plain-text Gmail API output adapter with one recipient per call, bounded input, sanitized results, and a least-privilege `gmail.send` OAuth scope.
- Reused the PostgreSQL notification outbox for stable source-key idempotency, concurrent claims, same-key payload conflict checks, rate-limit scheduling signals, and unknown-outcome holds.
- Added post-send outbox payload redaction while retaining the fingerprint needed to prevent duplicate sends.
- Bound `portfolio.gmail_send` to the existing PostgreSQL store and documented the operator limits, OAuth lifecycle gap, failure recovery, and account evidence.

## Evidence boundary

- Unit and synthetic Postgres integration validate adapter behavior; no Gmail API request was made by this module.
- One separately authorized self-addressed email was sent and verified through the connected Gmail app. That test does not verify the local runtime token or n8n OAuth credentials.
- No lead follow-up has been composed: client-approved message text, sender policy, qualification, and suppression conditions remain unresolved.
