# 0.3.0 — GHL contact adapter

## Added

- Added reusable `crm.ghl_upsert_contact`, a GoHighLevel API v3 contact upsert adapter with dry-run/mock modes, field allow-listing, PII-suppressed results, and explicit uncertain-outcome handling.
- Added synthetic HTTP tests and contract documentation for GHL contact duplicate policy, secret setup, rate limits, retry/reconciliation, and the tag-replacement hazard.

## Limits

- No live HighLevel account, Location ID, token, or business field mapping was available. No CRM write or live account verification occurred.
- Opportunity upsert, tag operations, AI qualification, outbound email, follow-up stop conditions, and n8n runtime import/execution remain outside this adapter and are not represented as completed.
