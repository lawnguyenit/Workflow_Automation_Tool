# Release 0.9.0 — Durable lead qualification and additive GHL tags

## Added

- `PostgresLeadQualificationLedger` serializes REAL qualification by a hash of the stable source event identity.
- Completed, contact-redacted results are cached with source content, criteria, model, and prompt fingerprints. Replays reuse the result; changed input/criteria are held for review.
- Durable `IN_PROGRESS`/`UNKNOWN` attempts block automatic retry until reconciliation.
- Atomic per-model UTC-day attempted-call counter; REAL qualification fails closed unless `LEAD_LLM_MAX_CALLS_PER_DAY` is explicitly configured.
- Migration `infra/postgres/migrations/004-lead-qualification-ledger.sql` and matching fresh-install schema in `infra/postgres/init.sql`.
- `crm.ghl_contact_tags`: bounded additive tag writes through HighLevel API v3 with shared PostgreSQL concurrency/unknown-outcome guard. It is separate from contact upsert to avoid replacing the full tag list.

## Operational limits

- The daily cap limits attempted request count, not USD spend. Provider token usage and current model prices are not collected or used to enforce a financial budget. Also set an account-side provider limit before real calls.
- A worker crash after the durable claim but before a request may consume one count and require manual reconciliation; this is intentional fail-safe behavior.
- The module does not enable live model use by itself. The portfolio has no API key, owner rubric, or request cap configured.
- The tag adapter has only synthetic HTTP evidence. It is not composed into the lead workflow without account-approved tag names and a GHL Location; no provider-side idempotency guarantee is claimed.

- Docker/PostgreSQL GHL tags integration used `httpx.MockTransport`: same-contact overlap made one synthetic provider request; an unknown timeout blocked a retry pending reconciliation. Synthetic reconciliation rows were removed. It did not contact HighLevel.

- No external model, Google Forms, or HighLevel request and no prospect data were used. See [current verification](../project-state/verification.md).
