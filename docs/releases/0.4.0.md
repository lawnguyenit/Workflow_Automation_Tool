# 0.4.0 — configurable lead qualification

## Added

- Added `lead.qualify`, a rubric-driven OpenAI Responses API module with strict structured output, confidence/missing-information validation, PII minimization, fixture/replay modes, and a manual-review gate.
- Composed lead intake → qualification/review → PostgreSQL storage and sanitized qualification workflow responses so contact fields do not appear in intermediate API results.
- Added OpenAI API environment placeholders and module contract/failure documentation.

## Limits

- No client rubric or OpenAI API key is configured; all live model behavior is unverified.
- No durable qualification-call deduplication, response cache, or spend ceiling exists yet; a repeated REAL event can incur another provider call/cost.
- GHL, lead source ingestion, outbound email, opportunities, and follow-up stop conditions remain incomplete.
